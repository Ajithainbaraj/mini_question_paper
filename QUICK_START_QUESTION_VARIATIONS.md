## Step 3: Open Question Variations (10 seconds)

Look for the sidebar menu and click:

**🧠 Question Variations** (with "NEW" badge)

---

## Step 4: Upload Sample Questions (1 minute)

### Option A: Use Provided Sample

Use the pre-created file:
```
uploads/sample_math_questions.txt
```

This contains 50 mathematics questions across multiple topics.

### Option B: Create Your Own

Create a text file with questions in this format:

```txt
ALGEBRA - Quadratic Equations

Q1. Solve the quadratic equation: x² - 5x + 6 = 0

Q2. Find the roots of 2x² - 7x + 3 = 0

Q3. Form a quadratic equation whose roots are 3 and -2.

CALCULUS - Differentiation

Q4. Find the derivative of f(x) = x³ + 2x² - 5x + 7

Q5. If y = sin(x), find dy/dx

TRIGONOMETRY

Q6. Prove that sin²θ + cos²θ = 1

Q7. If sin θ = 3/5, find cos θ
```

## Step 6: Explore Variations (30 seconds)

### Click on Any Concept
Example: Click on "Quadratic Equations"

You'll see:
- All questions for that concept
- Variation patterns identified
- Example questions

### Generate Variations
Click **"Generate Variations"** on any question

You'll get **10 types of variations**:
1. Different Numbers
2. Different Equation Format
3. Formula-based Variation
4. Word Problem
5. Reverse Question
6. Application Question
7. Multi-step Question
8. Conceptual Variation
9. Changed Conditions
10. Different Solving Method

Each variation shows:
- 📝 Question
- 💡 Hint
- 📌 Formula
- 🪜 Steps
- 📊 Difficulty
- ✅ Full Solution (click to reveal)

## 🎯 Quick Examples

### Example 1: Simple Question

**Original Question:**
> Solve: x² - 5x + 6 = 0

**Click "Generate Variations" →**

**Variation 1: Different Numbers**
> Solve: 2x² - 7x + 3 = 0

**Variation 4: Word Problem**
> A rectangular garden's length is 5 meters more than its width. If the area is 6 square meters, find the dimensions.

**Variation 5: Reverse Question**
> The roots of a quadratic equation are 2 and 3. Form the equation.

---

### Example 2: Calculus Question

**Original Question:**
> Find the derivative of f(x) = x³

**Variations Generated:**
- Different function: f(x) = x⁴ + 2x²
- Word problem: Position function s(t) = t³, find velocity
- Application: Revenue function R(x) = x³ - 2x², find marginal revenue
- Multi-step: Find critical points of f(x) = x³ - 3x + 2

## 💡 Pro Tips

### For Best Results:

1. **Clear Question Format**
   - Use Q1, Q2, Q3 numbering
   - Or use 1., 2., 3. format
   - Include chapter headings

2. **Quality Over Quantity**
   - 20-50 questions work best
   - Ensure diverse question types
   - Cover multiple concepts

3. **Explore Thoroughly**
   - Click through concepts
   - Generate variations for different question types
   - Compare variation patterns

4. **Use Filters**
   - Filter by difficulty to focus practice
   - Filter by pattern type for specific skills
   - Filter by chapter for focused study

5. **Download Reports**
   - Export PDF for offline study
   - Print specific variations
   - Share with study groups

## 🐛 Troubleshooting

### Issue: "No questions extracted"
**Fix:** Ensure questions have clear numbering (Q1, Q2, etc.)

### Issue: "Concepts seem wrong"
**Fix:** Add chapter headings to your file

### Issue: "Variations are similar"
**Fix:** Original question may be too specific - try broader concepts

### Issue: "Upload failed"
**Fix:** Check file size (< 10MB) and format (PDF/TXT/DOCX)
