┌─────────────────────────────────────────────────────────────────────────────┐
│                           USER INTERACTION FLOW                              │
└─────────────────────────────────────────────────────────────────────────────┘

    👤 User
      │
      ├─► Navigate to "Question Variations" in sidebar
      │
      ├─► Upload Math Question Bank (PDF/TXT/DOC/DOCX)
      │       │
      │       ├── Sample format:
      │       │   ALGEBRA - Quadratic Equations
      │       │   Q1. Solve x² - 5x + 6 = 0
      │       │   Q2. Find roots of 2x² - 7x + 3 = 0
      │       │   ...
      │       │
      │       └── Supported: 50+ questions, multiple chapters
      │
      ├─► View Analytics Dashboard
      │       │
      │       ├── Total Questions: 50
      │       ├── Total Concepts: 12
      │       ├── Most Repeated: Quadratic Equations (8 questions)
      │       └── Possible Variations: 120 (12 × 10)
      │
      ├─► Explore Concept (e.g., "Quadratic Equations")
      │       │
      │       ├── View all 8 questions for this concept
      │       ├── See variation patterns identified
      │       └── Example questions shown
      │
      ├─► Generate Variations for a Question
      │       │
      │       └── Receive 10 variations:
      │           1. Different Numbers
      │           2. Different Equation Format
      │           3. Formula-based Variation
      │           4. Word Problem
      │           5. Reverse Question
      │           6. Application Question
      │           7. Multi-step Question
      │           8. Conceptual Variation
      │           9. Changed Conditions
      │           10. Different Solving Method
      │
      ├─► Study Each Variation
      │       │
      │       ├── Read Question
      │       ├── See Hint
      │       ├── View Formula
      │       ├── Follow Steps
      │       ├── Check Difficulty
      │       └── Reveal Full Solution (when ready)
      │
      └─► Download PDF Report or Print


┌─────────────────────────────────────────────────────────────────────────────┐
│                           BACKEND DATA FLOW                                  │
└─────────────────────────────────────────────────────────────────────────────┘

    📁 Upload File
          │
          ▼
    ┌──────────────────────┐
    │  Load Document       │  ← rag_pipeline.load_document()
    │  (PDF/TXT/DOCX)      │    Extracts raw text
    └──────────────────────┘
          │
          ▼
    ┌──────────────────────┐
    │  Clean & Prepare     │  ← Remove extra spaces, normalize
    └──────────────────────┘
          │
          ▼
    ┌──────────────────────────────────────────────────────────┐
    │  STEP 1: Analyze Question Bank                          │
    │  ┌────────────────────────────────────────────────────┐ │
    │  │ LLM: analyze_math_question_bank()                  │ │
    │  │                                                    │ │
    │  │ Input:  Question bank text (8000 chars max)       │ │
    │  │ Model:  openai/gpt-oss-120b via Groq             │ │
    │  │ Mode:   JSON structured output                    │ │
    │  │                                                    │ │
    │  │ Extracts for each question:                       │ │
    │  │   • Question text                                 │ │
    │  │   • Chapter (Algebra, Calculus, etc.)            │ │
    │  │   • Concept (Quadratic Equations, etc.)          │ │
    │  │   • Formula (x = [-b ± √(b²-4ac)] / 2a)         │ │
    │  │   • Pattern (Direct/Word Problem/etc.)           │ │
    │  │   • Difficulty (Easy/Medium/Hard)                │ │
    │  │   • Semantic key (solve_quadratic)               │ │
    │  │   • Keywords [quadratic, solve, roots]           │ │
    │  │                                                    │ │
    │  │ Output: JSON with all questions + metadata        │ │
    │  └────────────────────────────────────────────────────┘ │
    └──────────────────────────────────────────────────────────┘
          │
          ▼
    ┌──────────────────────────────────────────────────────────┐
    │  STEP 2: Find Question Variations                        │
    │  ┌────────────────────────────────────────────────────┐ │
    │  │ Group by Concept                                   │ │
    │  │   Quadratic Equations: [Q1, Q2, Q6, Q7, ...]      │ │
    │  │   Derivatives: [Q9, Q10, Q11, ...]                │ │
    │  │   Trigonometry: [Q16, Q17, Q18, ...]              │ │
    │  └────────────────────────────────────────────────────┘ │
    │          │                                                │
    │          ▼                                                │
    │  ┌────────────────────────────────────────────────────┐ │
    │  │ LLM: find_question_variations()                    │ │
    │  │                                                    │ │
    │  │ For each concept group:                           │ │
    │  │   • Analyze how questions vary                    │ │
    │  │   • Identify variation patterns                   │ │
    │  │   • Classify variation types                      │ │
    │  │   • Find example questions                        │ │
    │  │   • Generate pattern summary                      │ │
    │  │                                                    │ │
    │  │ Output: Variations map per concept                │ │
    │  └────────────────────────────────────────────────────┘ │
    └──────────────────────────────────────────────────────────┘
          │
          ▼
    ┌──────────────────────────────────────────────────────────┐
    │  STEP 3: Build Analytics                                 │
    │  ┌────────────────────────────────────────────────────┐ │
    │  │ build_variation_analytics()                        │ │
    │  │                                                    │ │
    │  │ Calculate:                                         │ │
    │  │   • Total questions, concepts, chapters           │ │
    │  │   • Most repeated concept                         │ │
    │  │   • Most common pattern                           │ │
    │  │   • Chapter distribution                          │ │
    │  │   • Concept frequency                             │ │
    │  │   • Pattern frequency                             │ │
    │  │   • Difficulty distribution                       │ │
    │  │   • Variation type frequency                      │ │
    │  │                                                    │ │
    │  │ Output: Analytics dictionary                      │ │
    │  └────────────────────────────────────────────────────┘ │
    └──────────────────────────────────────────────────────────┘
          │
          ▼
    ┌──────────────────────┐
    │  Store in Session    │  ← Flask session
    │  • analytics         │
    │  • questions         │
    │  • variations_map    │
    └──────────────────────┘
          │
          ▼
    ┌──────────────────────┐
    │  Render Dashboard    │  ← question_variations.html
    └──────────────────────┘

    User clicks "Generate Variations" on Question #5
          │
          ▼
    ┌──────────────────────────────────────────────────────────┐
    │  Retrieve Original Question from Session                 │
    │    {                                                     │
    │      "id": 5,                                           │
    │      "question": "Solve x² - 5x + 6 = 0",              │
    │      "chapter": "Algebra",                             │
    │      "concept": "Quadratic Equations",                 │
    │      "formula": "x = [-b ± √(b²-4ac)] / 2a",          │
    │      "difficulty": "Medium"                            │
    │    }                                                    │
    └──────────────────────────────────────────────────────────┘
          │
          ▼
    ┌──────────────────────────────────────────────────────────┐
    │  LLM: generate_question_variations()                     │
    │  ┌────────────────────────────────────────────────────┐ │
    │  │ Prompt includes:                                   │ │
    │  │   • Original question                              │ │
    │  │   • Chapter, concept, formula                      │ │
    │  │   • Instruction to generate 10 variations          │ │
    │  │   • Detailed format for each variation             │ │
    │  │                                                    │ │
    │  │ Model generates:                                   │ │
    │  │                                                    │ │
    │  │ 1. Different Numbers:                              │ │
    │  │    Q: Solve 2x² - 7x + 3 = 0                       │ │
    │  │    Hint: Use quadratic formula                     │ │
    │  │    Formula: Same as original                       │ │
    │  │    Steps: [Identify a,b,c, Apply formula, ...]    │ │
    │  │    Solution: x = 3 or x = 0.5                      │ │
    │  │                                                    │ │
    │  │ 2. Reverse Question:                               │ │
    │  │    Q: Form equation with roots 2 and 3             │ │
    │  │    Hint: Use (x-α)(x-β) = 0                       │ │
    │  │    Formula: x² - (sum)x + (product) = 0           │ │
    │  │    Steps: [Sum = 5, Product = 6, ...]             │ │
    │  │    Solution: x² - 5x + 6 = 0                       │ │
    │  │                                                    │ │
    │  │ 3. Word Problem:                                   │ │
    │  │    Q: A garden's length is 5m more than width...   │ │
    │  │    Hint: Let width = x, then length = x+5          │ │
    │  │    Formula: Area = length × width                  │ │
    │  │    Steps: [Set up equation, Simplify, Solve]      │ │
    │  │    Solution: width = 1m, length = 6m               │ │
    │  │                                                    │ │
    │  │ ... (7 more variations)                            │ │
    │  │                                                    │ │
    │  │ Output: JSON with 10 complete variations           │ │
    │  └────────────────────────────────────────────────────┘ │
    └──────────────────────────────────────────────────────────┘
          │
          ▼
    ┌──────────────────────┐
    │  Parse JSON          │
    └──────────────────────┘
          │
          ▼
    ┌──────────────────────┐
    │  Render Detail Page  │  ← question_variations_detail.html
    │  • Original question │
    │  • 10 variation cards│
    │  • Expandable solutions│
    └──────────────────────┘
