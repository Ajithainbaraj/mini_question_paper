STEP 1: CHECK CURRENT STATUS
=================================================================

# Check git status
git status

# Check current branch
git branch

# Expected: You should be on 'main' branch
# Expected: You should see modified files listed


=================================================================
STEP 2: ADD ALL CHANGES
=================================================================

# Add all new and modified files
git add .

# Verify what was added
git status


=================================================================
STEP 3: COMMIT CHANGES
=================================================================

# Commit with descriptive message
git commit -m "Add Question Variations feature and update LLM model to openai/gpt-oss-120b"


=================================================================
STEP 4: PUSH TO REMOTE (CHOOSE YOUR PLATFORM)
=================================================================

─────────────────────────────────────────────────────────────────
OPTION A: RENDER (Push to GitHub/GitLab, Render auto-deploys)
─────────────────────────────────────────────────────────────────

# Push to origin (GitHub/GitLab)
git push origin main

# Render will automatically detect and deploy
# Monitor: https://dashboard.render.com
# Wait: 5-15 minutes for deployment

─────────────────────────────────────────────────────────────────
OPTION B: HEROKU (Direct push to Heroku)
─────────────────────────────────────────────────────────────────

# First, check if heroku remote exists
git remote -v

# If heroku remote exists:
git push heroku main

# If heroku remote doesn't exist, add it:
heroku git:remote -a your-app-name

# Then push:
git push heroku main

# Watch logs:
heroku logs --tail

─────────────────────────────────────────────────────────────────
OPTION C: BOTH (Push to both remotes)
─────────────────────────────────────────────────────────────────

# Push to GitHub (for backup/version control)
git push origin main

# Push to Heroku (for deployment)
git push heroku main


=================================================================
STEP 5: VERIFY ENVIRONMENT VARIABLES (ONE-TIME SETUP)
=================================================================

─────────────────────────────────────────────────────────────────
FOR RENDER (via Dashboard)
─────────────────────────────────────────────────────────────────

1. Go to: https://dashboard.render.com
2. Click your service
3. Go to "Environment" tab
4. Add/Update:
   - GROQ_API_KEY = your_actual_groq_api_key_here

─────────────────────────────────────────────────────────────────
FOR HEROKU (via CLI)
─────────────────────────────────────────────────────────────────

# Set Groq API key
heroku config:set GROQ_API_KEY=your_actual_groq_api_key_here

# Verify it's set
heroku config

# You should see:
# GROQ_API_KEY: gsk_...

=================================================================
COMMON ISSUES & FIXES
=================================================================

ISSUE: "Model not found" error
FIX:   Verify MODEL = "openai/gpt-oss-120b" in question_generator.py
       git add question_generator.py
       git commit -m "Fix model name"
       git push

ISSUE: Templates not found (404 on /question-variations)
FIX:   Verify templates committed:
       git add templates/
       git commit -m "Add variation templates"
       git push

ISSUE: Environment variable not set
FIX:   # Render: Dashboard → Environment → Add GROQ_API_KEY
       # Heroku: heroku config:set GROQ_API_KEY=your_key

ISSUE: Build fails
FIX:   Check logs for specific error
       Verify requirements.txt is correct
       Clear build cache and redeploy

ISSUE: Timeout errors
FIX:   Already fixed - Procfile has timeout=120
