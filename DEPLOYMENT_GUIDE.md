## Deployment Steps

### Option 1: Render.com (Recommended)

#### Step 1: Prepare Your Repository

```bash

git status

# 2. Add all new files
git add .
```

#### Step 2: Deploy on Render

1. **Login to Render.com**
   - Go to https://render.com

2. **Update Existing Service** (if you already deployed before)
   - Go to your Dashboard
   - Click on your existing "eduai" service

3. **Monitor the Deployment**

4. **Verify Environment Variables**
   - Go to "Environment" tab

#### Step 3: Test the Deployment

1. **Open Your Deployed App**
   - URL: `https://your-app-name.onrender.com`

2. **Test Login**
   - Login with: admin / admin123

3. **Test Question Variations**

### Option 3: Docker Deployment

#### Step 1: Create Dockerfile (if not exists)

```dockerfile
FROM python:3.11-slim

WORKDIR /app

# Install system dependencies
RUN apt-get update && apt-get install -y \
    build-essential \
    && rm -rf /var/lib/apt/lists/*

# Copy requirements
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy application
COPY . .

# Create necessary directories
RUN mkdir -p uploads papers vector_store

# Expose port
EXPOSE 10000

# Run the application
CMD ["gunicorn", "app:app", "--bind", "0.0.0.0:10000", "--workers", "1", "--timeout", "120"]
```

#### Step 2: Build and Run

```bash
# Build Docker image
docker build -t eduai:latest .

# Run container
docker run -d \
  -p 10000:10000 \
  -e GROQ_API_KEY=your_api_key \
  -e SECRET_KEY=your_secret_key \
  --name eduai \
  eduai:latest

# View logs
docker logs -f eduai
```

## Troubleshooting

### Issue: "Model not found" Error

**Problem:** Old model name still in code  
**Solution:** Verify `question_generator.py` has `MODEL = "openai/gpt-oss-120b"`

```bash
# Check current model
grep "MODEL =" question_generator.py

# Should show: MODEL = "openai/gpt-oss-120b"
```

### Issue: Import Errors

**Problem:** Missing dependencies  
**Solution:** Verify all packages in requirements.txt

```bash
# Rebuild on Render
# Click "Manual Deploy" → "Clear build cache & deploy"

# Or on Heroku
heroku restart
```

### Issue: Timeout on Variation Generation

**Problem:** Gunicorn timeout too short  
**Solution:** Already set to 120s in Procfile ✅

```
web: gunicorn app:app --bind 0.0.0.0:$PORT --workers 1 --timeout 120
```

### Issue: Session Data Lost

**Problem:** Session storage limitations  
**Solution:** Use external session storage or database (future enhancement)

**Workaround:** Use "Download Report" frequently to save progress

### Issue: 404 on New Routes

**Problem:** Server not restarted after deployment  
**Solution:** 

**Render:** Auto-restarts ✅  
**Heroku:**
```bash
heroku restart
```

**Docker:**
```bash
docker restart eduai
```

### Issue: Templates Not Found

**Problem:** Template files not committed  
**Solution:**

```bash
# Verify templates exist
ls templates/question_variations*.html

# Should show:
# question_variations.html
# question_variations_concept.html
# question_variations_detail.html
# question_variations_filtered.html

# If missing, commit them
git add templates/
git commit -m "Add variation templates"
git push
```
